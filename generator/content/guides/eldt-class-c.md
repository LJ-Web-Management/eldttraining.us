:::answer
**No ELDT is required just to get a Class C CDL**, because the federal ELDT rule covers Class A and Class B. But a Class C CDL is only needed when a vehicle carries 16+ passengers or placarded hazmat, so Class C drivers almost always need an endorsement, and **first-time P, S, or H endorsements do require ELDT**. A Class C passenger-van driver needs P endorsement ELDT; a Class C hazmat delivery driver needs hazmat ELDT.
:::

## What is a Class C CDL?

Under 49 CFR 383.91, Class C covers any single vehicle or combination that doesn't meet the Class A or Class B weight definitions but is either:

- **Designed to transport 16 or more passengers**, including the driver, or
- **Used to transport hazardous materials** in a quantity requiring placards (or certain select agents and toxins)

Typical Class C jobs: large passenger vans and small shuttle buses, smaller school or activity buses, and lighter hazmat delivery trucks (propane, chemicals) under 26,001 lbs.

## How ELDT applies to Class C

| Class C situation | ELDT required? | Course |
|---|---|---|
| Class C CDL with no endorsements | No (federal) | — |
| Class C + first-time Passenger (P) | **Yes** | [Passenger (P) ELDT](/products/cdl-entry-level-driver-training-eldt-passenger-p-endorsement) |
| Class C + first-time School Bus (S) | **Yes** (plus P) | [School Bus (S) ELDT](/products/cdl-entry-level-driver-training-eldt-school-bus-s-endorsement) |
| Class C + first-time Hazmat (H) | **Yes** | [Hazmat (H) ELDT](/products/cdl-entry-level-driver-training-eldt-hazmat-h-endorsement) |
| Class C + Tanker (N) | No (federal) | Optional [N training](/products/cdl-entry-level-driver-training-eldt-tanker-n-endorsement) |

For P and S, ELDT includes theory plus behind-the-wheel training in a representative vehicle. For H, theory alone is enough.

## Class C vs Class B

If the vehicle has a GVWR of 26,001 lbs or more, it's Class B (or A), not Class C, and Class B ELDT applies. A full-size transit bus or most school buses fall into Class B. Smaller 15- to 24-passenger buses under 26,001 lbs are often Class C.

## Frequently asked questions

### Can I take Class C ELDT online?
There's no separate "Class C ELDT." You take the endorsement course you need (P, S, or H). Theory for all three can be completed online; P and S also need behind-the-wheel training.

### Do I need a CDL to drive a 15-passenger van?
A van designed for 15 or fewer passengers including the driver generally doesn't require a CDL. Vehicles designed for 16 or more (including the driver) do. Check the manufacturer's rated seating capacity.

### Is Class C the same as a regular driver's license?
No. In many states a regular non-commercial license is also called "Class C," which causes confusion. A Class C CDL is a commercial license issued under federal CDL standards.

### Do I need a medical card for a Class C CDL?
Most Class C CDL holders operating in interstate commerce need a DOT medical examiner's certificate. See [DOT physical and medical card](/guides/dot-physical-medical-card).
