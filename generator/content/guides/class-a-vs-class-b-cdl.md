:::answer
**The difference is towing: a Class A CDL covers combination vehicles over 26,000 lbs towing more than 10,000 lbs (tractor-trailers), while a Class B CDL covers heavy single vehicles 26,001+ lbs that tow 10,000 lbs or less (dump trucks, box trucks, buses).** Class A covers Class B vehicles too, opens more jobs, and usually pays more, but takes a bit more training. If you're unsure, Class A is the more flexible choice, and completing Class A ELDT also lets you take the Class B skills test.
:::

## Class A vs Class B at a glance

| | Class A | Class B |
|---|---|---|
| Vehicle type | Combination vehicles | Single heavy vehicles |
| Weight rule | GCWR 26,001+ lbs, towed unit >10,000 lbs | GVWR 26,001+ lbs, towing ≤10,000 lbs |
| Examples | Tractor-trailers, tankers, flatbeds | Dump trucks, box trucks, buses, garbage trucks |
| Can drive the other class? | Yes, can drive Class B and C | No Class A vehicles |
| Extra knowledge test | Combination Vehicles | None |
| ELDT course | [Class A](/products/entry-level-driver-training-eldt-class-a) ($129.99, ~15 hrs) | [Class B](/products/entry-level-driver-training-eldt-class-b) ($119.99, ~13 hrs) |
| BTW range skills | Includes coupling/uncoupling | No coupling |
| Typical job style | OTR, regional, local | Mostly local, home daily |

## Which should you get?

**Choose Class A if** you want the most job options, over-the-road or regional trucking, tanker or flatbed work, or the highest earning potential.

**Choose Class B if** you know you want a local job driving a dump truck, delivery truck, garbage truck, or bus, and you don't plan to tow heavy trailers.

:::tip Avoid paying for ELDT twice
Upgrading from Class B to Class A later counts as entry-level training under federal rules, so you'd complete Class A ELDT then. If there's a real chance you'll want Class A, it's usually cheaper to start there.
:::

## Pay and job outlook

Class A drivers generally have access to more and higher-paying jobs, especially long-haul and specialized freight. Class B jobs often trade some pay for predictable local schedules and benefits, especially in municipal, utility, and transit work. Endorsements (hazmat, tanker, passenger) raise earning potential in both classes. See [CDL endorsements](/guides/cdl-endorsements).

## Frequently asked questions

### Is Class A harder than Class B?
A little. Class A adds the Combination Vehicles test, coupling and uncoupling, and more challenging backing with a trailer. Most people who train properly pass either.

### Can I drive a bus with a Class A CDL?
Yes, if you have the Passenger (P) endorsement (and S for school buses) and no restriction preventing it.

### Does Class A ELDT cover Class B?
Yes. FMCSA allows drivers who completed Class A ELDT to take the Class B skills test. Class B ELDT doesn't qualify you for Class A.

### What's a Class C CDL?
Class C covers smaller vehicles that carry 16+ passengers or placarded hazmat. See [ELDT for Class C](/guides/eldt-class-c).
