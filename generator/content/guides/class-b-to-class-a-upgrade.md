**To upgrade from Class B to Class A, you need a Class A commercial learner's permit (pass the Combination Vehicles test, plus Air Brakes if you haven't), Class A ELDT theory and behind-the-wheel training from FMCSA-registered providers, a 14-day CLP holding period, and a passing Class A skills test.** The federal ELDT rule specifically lists a Class B to Class A upgrade as entry-level training, so you can't skip it, even with years of Class B experience.
:::

## Step-by-step upgrade

1. **Check your medical certificate** is current.
2. **Pass the Class A knowledge tests** your state requires, typically Combination Vehicles (and Air Brakes if your Class B has an air brake restriction).
3. **Get your Class A CLP** and hold it for at least 14 days.
4. **Complete Class A upgrade theory** with a registered provider. Our [Class B to A Upgrade course](/products/entry-level-driver-training-eldt-class-b-to-a-upgrade) is about 12 hours, focused on combination-vehicle knowledge.
5. **Complete Class A BTW training** with a registered provider: range (coupling, uncoupling, backing with a trailer) and public road in a combination vehicle.
6. **Take the Class A skills test.** Your state checks the TPR for your Class A ELDT records first.

## Why experienced drivers still need ELDT

49 CFR 380.609 requires ELDT for anyone "upgrading" from a Class B to a Class A CDL. The rule is about the license class, not experience. Your Class B experience helps you move through BTW faster, since there's no minimum hours and your instructor certifies proficiency.

## Frequently asked questions

### Do I need ELDT to upgrade from B to A if I got my Class B before 2022?
Yes. The exemption for pre-February 7, 2022 licenses only covers the class you already held. A Class A is a new class for you.

### Can I keep driving my Class B truck while I train?
Yes. Your Class B CDL stays valid. The Class A CLP only adds permission to practice in combination vehicles with a qualified Class A driver.

### Do I need to retake the general knowledge test?
Usually not, if your Class B is valid. States typically require only the Combination Vehicles test (and Air Brakes if needed), but check your state's rules.

### Does upgrading change my endorsements?
Your existing endorsements generally carry over. Adding new ones (like hazmat) is separate.
