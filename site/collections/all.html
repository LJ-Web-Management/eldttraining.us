How to choose the right course

  • Tractor-trailer, OTR, regional, flatbed, or tanker trucking: Class A.
  • Dump truck, box truck, cement mixer, garbage truck, or bus: Class B (add P for buses).
  • Already hold a Class B and want tractor-trailer work: Class B to A Upgrade.
  • Hauling placarded hazardous materials: Hazmat (H), or X (Hazmat + Tanker) for hazmat in tanks.
  • Driving a bus or vehicle designed for 16+ passengers: Passenger (P).
  • Driving a school bus: Passenger (P) + School Bus (S).
  • Non-hazmat liquid tankers: Tanker (N).

Frequently asked questions

Which ELDT course should I take?

Match the course to the license or endorsement you are applying for: Class A for tractor-trailers and combination vehicles, Class B for straight trucks and buses, the B-to-A upgrade if you already hold a Class B, and the H, P, or S course for each first-time endorsement.

Do I need more than one course?

Possibly. Each license class and each ELDT endorsement is a separate training type. A new school bus driver, for example, typically needs Class B, Passenger (P), and School Bus (S).

Are these courses accepted in my state?

Yes. ELDT is a federal requirement and every state checks the same FMCSA Training Provider Registry. Online theory from a registered provider counts nationwide.

Do the courses include behind-the-wheel training?

No. These are theory courses. Class A, Class B, P, and S also require behind-the-wheel training with a registered BTW provider, such as a CDL school or a carrier's training program.
